# 一问成卷 | FormSight

一问成卷（FormSight）是一个基于 Vue 3 和 WXT 的浏览器扩展，用 AI 识别网页问卷、通过自然语言对话补全答案，并在用户审核后填写到当前页面。

项目采用无后端设计：AI 请求直接发送到用户配置的 OpenAI 兼容接口，API Key 和当前问卷会话保存在浏览器本地。

## 功能

- 扫描常见的文本框、文本域、下拉框、单选、多选和 `contenteditable` 控件。
- 将页面文本、控件属性和语义上下文交给 AI，辅助识别复杂问卷字段。
- 支持三种询问模式：
  - **敷衍**：不主动追问，直接生成合理的完整答案。
  - **正常**：只确认关键歧义，其余内容根据上下文合理推断。
  - **认真**：确认关键歧义，支持不限轮次的精简对话；仍无法判断的内容会合理推断或生成。
- AI 输出实时显示，字段摘要默认折叠，待填写答案默认展示 3 项。
- 填写前保留人工审核环节，不自动提交网页表单。
- 兼容 OpenAI Chat Completions 格式的服务，包括自部署或第三方兼容接口。

## 安装使用

### 直接安装发布包

1. 打开本项目的 [Releases](../../releases) 页面。
2. 下载最新版本的扩展压缩包。
3. 在 Edge 或 Chrome 中打开 `扩展` 管理页，开启开发者模式。
4. 解压压缩包，点击“加载解压缩的扩展”，选择解压后的扩展目录。
5. 打开扩展设置，填写 Base URL、Model 和 API Key。
6. 回到问卷页面，点击右下角浮窗，选择询问模式后开始扫描。

### 本地开发

环境要求：Node.js 18+、pnpm 8+。

```bash
pnpm install
pnpm dev
```

开发模式启动后，在浏览器扩展管理页加载 WXT 输出的开发目录。

### 构建和打包

```bash
pnpm build
pnpm zip
```

构建目录和发布压缩包会生成在 `.output/` 下。该目录已加入 `.gitignore`，发布时作为 GitHub Release 附件上传。

## AI 配置

Base URL 填写服务商的 API 根地址，例如 `https://api.example.com/v1`；扩展会自动请求 `/chat/completions`。Model 填写服务商实际提供的模型名称。

为了兼容不支持 `temperature` 的新模型，扩展请求体不会发送 `temperature` 参数。结构化输出仍由提示词和本地 Zod 校验共同约束。

## 隐私和权限

- 项目没有自建后端，API Key 不会发送到本项目维护者的服务器。
- API Key、设置和临时问卷会话使用浏览器扩展存储，建议使用低权限、低额度的专用 Key。
- 当前页面的标题、地址、可见文本、表单字段和对话内容可能会发送给你配置的 AI 服务商，请在使用前确认服务商的数据处理政策。
- 扩展需要网页访问权限才能扫描和填写当前页面；它不会替用户点击最终提交按钮。
- 不要在公共仓库、截图或 Issue 中提交 API Key、完整问卷隐私数据或其他凭据。

## 当前边界

- 不同网站的自定义控件、分页问卷、登录态和强交互组件可能需要人工补充或重新扫描。
- AI 生成的答案仅供辅助，不能替代用户对事实、隐私和合规性的审核。
- 复杂页面可以由 AI 归纳字段，但如果页面没有可定位的真实控件，暂时无法自动回填。
